� Problema de Permisos:

Firebase está configurado para no permitir registro desde el cliente. Debes crear el usuario manualmente en la consola de Firebase:

📊 Pasos para crear usuario test:

  1. Ve a Firebase Console
  2. Selecciona tu proyecto "medicalweboffline"
  3. Ve a Authentication > Users
  4. Haz clic en "Add user"
  5. Crea el usuario con estos datos:
    • Email: test@medical.com
    • Contraseña: test123456
  6. Luego ve a Firestore Database > usuarios
  7. Crea un documento con el UID del usuario creado y estos datos: 
    {
  "nombre": "Usuario Test",
  "apellidos": "Apellidos Test", 
  "correo": "test@medical.com",
  "matricula": "TEST001",
  "rol": "admin",
  "edad": 25,
  "sexo": "M",
  "grupo_trabajo": "TEST_GROUP",
  "fechaCreacion": firebase.firestore.Timestamp.now()
}
