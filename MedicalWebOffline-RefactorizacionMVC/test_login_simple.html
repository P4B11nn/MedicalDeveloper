🚨 IMPORTANTE: Crear Usuario Manualmente

Debido a la configuración de seguridad de Firebase, debes crear el usuario manualmente. Sigue estos pasos:

Paso 1: Crear usuario en Firebase Authentication

  1. Ve a Firebase Console
  2. Selecciona tu proyecto "medicalweboffline"
  3. Ve a Authentication > Users
  4. Haz clic en "Add user"
  5. Introduce:
    • Email: test@medical.com
    • Password: test123456
  6. Haz clic en "Add user"
  7. ¡IMPORTANTE! Copia el UID que se genera

Paso 2: Crear documento en Firestore

  1. Ve a Firestore Database > Data
  2. Si no existe, crea la colección "usuarios"
  3. Crea un nuevo documento con el UID que copiaste como ID del documento
  4. Agrega estos campos:
    { "apellidos": "Test Apellidos", "correo": "test@medical.com", "edad": 25, "grupo_trabajo": "TEST_GROUP", "matricula": "TEST001", "nombre": "Usuario Test", "rol": "admin", "sexo": "M" }
